# Drone Hunt — Operação Núcleo

Jogo 3D para uma pessoa, criado por Gabriel e desenvolvido com apoio de IA.

Enfrente quatro ondas de drones, escolha melhorias para o equipamento e derrote o chefe final. Funciona no navegador em computador e celular.

## Versões

- [Jogar a versão melhorada](./index.html)
- [Jogar a versão original do Gabriel](./original/index.html)

A versão original foi preservada sem alterações.

## Como jogar

- **WASD:** mover.
- **Mouse:** mirar e atirar.
- **Shift:** correr.
- **Espaço:** pular.
- **Q:** usar o canhão.
- **H:** usar a cura.
- **Esc:** pausar.
- **Celular:** use os controles de toque com a tela na horizontal.

Recorde e progresso são guardados neste navegador. Não há conta, servidor de partidas ou modo multijogador.

## Publicação

O jogo está em `index.html`, com modelos, sons e código incorporados. Para publicar no GitHub Pages, selecione **Deploy from a branch**, a branch **main** e a pasta **/ (root)** nas configurações de Pages.

Para executar localmente, sirva esta pasta com um servidor HTTP, por exemplo `python -m http.server 8000`, e abra `http://localhost:8000`.
